# Chapter 2 · Materials

Frequency-dependent electric and magnetic materials in the time domain via auxiliary differential equations (ADE), nonlinear least-squares pole fitting to measured optical and biological-tissue data, and dispersive permeability $\mu(\omega)$ from magnetization dynamics.
